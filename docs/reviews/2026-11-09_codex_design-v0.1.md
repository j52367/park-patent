**1. 치명적 문제 (설계가 실패할 수 있는 지점)**

- **근거 원칙과 데이터가 충돌합니다(§3·6).** 오프라인 데이터에는 청구항·본문이 없어 모든 판정에 청구항/문단 인용을 붙일 수 없습니다. 초록 기반 잠정 선별과 전문 기반 확정 판정을 구분하고, 문헌 버전·근거 위치를 저장해야 합니다. SWOT에는 시장·사업 자료도 필요합니다.
- **검색 범위보다 결론이 넓습니다(§5·10).** KR 특허만으로 신규성·공백기술을 판단하면 해외 문헌·논문·제품 공개를 놓칩니다. 한국 특허의 선행기술도 국내외 공개를 포함합니다. MVP 결과를 ‘KR 공개특허 동향’으로 한정해야 합니다. [특허법 제29조](https://www.law.go.kr/법령/특허법/제29조)
- **누락을 검출하는 평가가 없습니다(§8).** 정확도와 다른 모델의 점수만으로 핵심특허 탈락을 잡기 어렵습니다. 검색 재현율, 스크리닝 거짓음성률, 인용의 주장 뒷받침 여부를 평가하고, 심결문 인용문헌을 유일한 정답으로 취급하지 않아야 합니다.

**2. 한국 특허 실무 관점에서 빠졌거나 틀린 것**

- **유효특허·핵심특허·권리 존속을 별도 축으로 관리해야 합니다.** 동향조사의 유효특허는 통상 노이즈를 제거한 기술 관련 문헌입니다. ‘노이즈/유효/핵심’ 단일 라벨은 관련성과 중요도를 섞습니다. 등록 여부를 핵심 라벨에서 제외한 방향은 타당합니다. [특허청 분석 사례](https://www.kipo.go.kr/upload/newletter/displaynews/strechable.pdf)
- **청구항 대비 목적이 혼재합니다.** 신규성은 원칙적으로 단일 선행문헌과, 진보성은 결합 논리까지 검토합니다. 제품 회피설계에는 제29조 외에 제97조에 따른 청구범위 해석, 전 구성요소 대응 및 균등침해 검토가 필요합니다. [제97조](https://www.law.go.kr/법령/특허법/제97조)
- **기준일·문헌 버전이 빠졌습니다.** 청구항별 우선권 기준일, 선행문헌 공개일, 공개·등록·정정 청구항을 구별해야 합니다. 현재 권리상태도 등록 플래그만으로 판단할 수 없습니다.
- **특허맵 집계 규칙이 부족합니다.** 출원/공개 중복 제거, 패밀리 집계 단위, 출원인 정규화, 공동출원 배분, 국적 정의가 필요합니다. 최근 약 18개월의 미공개 구간을 표시하고, 출원인 수×출원 건수만으로 성장단계를 단정하지 마십시오. [공개제도 안내](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=2&cciNo=1&cnpClsNo=2&csmSeq=724)
- **API 한도 단위가 틀렸습니다.** 월 1,000‘건’이 아니라 1,000‘회 호출’이며 페이지당 최대 30~500건입니다. 상품별 신청·연간 갱신도 반영하십시오. `getFamilySearch`의 현재 호환성과 청구항·상태 제공 상세는 **(불확실)**하므로 실제 응답으로 검증해야 합니다. [공식 FAQ](https://plus.kipris.or.kr/portal/bbs/Faq_info.do?buttonIndex=&pageIndex=2)

**3. MVP 범위 조정 제안**

- **CSV 입력→기술 관련성 선별→기본 맵→HTML**로 고정하고, API는 검색·서지 한 경로부터 검증하십시오.
- 무효 공방, 회피설계·라이선스 전략, 가치예측, 모델 학습은 후속으로 미루십시오.
- 완료 기준에 전문가 라벨 평가, 탈락 표본 재검토, 집계 일치, 근거 링크 검증과 실행 비용을 추가하십시오.

**4. 오픈소스로서 채택/기여를 늘리기 위한 제안**

- `skills/*.md` 도식에서 실제 설치 가능한 `skills/<이름>/SKILL.md` 패키지와 설치 경로를 명시하십시오. WSL·특정 구독 의존은 선택 사항으로 두십시오. [공식 스킬 규격](https://code.claude.com/docs/en/skills)
- 산출물 스키마·버전, 재시작 방식, API 오류 처리를 공개하고, 키 없이 실행되는 합성 데이터 데모와 CI를 제공하십시오.
- 코드·스킬·데이터·모델의 라이선스를 구분하고, 재배포 허용 샘플과 기여 지침을 제공하십시오. 기밀 입력의 외부 모델 전송 여부도 사용자가 선택할 수 있어야 합니다.
